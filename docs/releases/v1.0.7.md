# Terradune v1.0.7

## A Patched Toolchain

**Upgrade for the standard library.** Go 1.27.1, which every earlier release
built with, carries four vulnerabilities in `net/http` and its HTTP/2
implementation that Terradune's server reaches (GO-2026-6611, GO-2026-6612,
GO-2026-6613, GO-2026-6617). This release names Go 1.27.3 in `go.mod`, so
`go install` builds it, and every later copy, with the patched library.
`golang.org/x/text` moves to 0.41.0, which closes GO-2026-6629. The server is
loopback-only, so the practical exposure was low; the fix is still the
toolchain, and it is in this release.

## Defense In Depth In The Browser

- The server now sends a Content-Security-Policy: scripts, styles, fonts,
  images and connections from its own origin only, the page's own inline
  blocks allowed by their hashes, nothing framed, no forms, no base URL.
  Plan values were already escaped before they reached markup; the policy is
  the layer behind that, and the browser suite runs every view under it.
- Map cards and graph nodes are named by what they show. A card called
  "platform-public-us-east-1a, Subnet, 10.20.0.0/24, existing" is read to a
  screen reader as exactly that, followed by "pin path"; a voice-control user
  can say the words on the card. axe-core 4.14 flags the previous
  `aria-label` names, and now runs in the browser suite.

## Install Or Upgrade

```sh
go install github.com/albatroxxx/terradune@v1.0.7
terradune -version
```

Go 1.27.3 or newer is the documented minimum. An older 1.27 toolchain still
works: Go downloads the version named in `go.mod` on first use. Go remains the
only supported installation method; no infrastructure is applied. Existing
stable tags are unchanged.

## For Contributors

Every GitHub Action and scanner in CI is pinned to a commit and Dependabot
proposes grouped updates, so a bumped `codeql-action/init` can no longer
arrive without its `analyze`. Fuzz targets cover the plan and DOT parsers, the
listen address, the Host allowlist and the resource lookup; CI runs them for
ten seconds each. The repository gains a root `CONTRIBUTING.md`,
`GOVERNANCE.md`, a code of conduct, a pull request template, a feature request
form, a [threat model](https://github.com/albatroxxx/terradune/blob/v1.0.7/docs/THREAT-MODEL.md)
and a security policy that says what counts as a vulnerability and how fixes
ship.

## Validation

Race tests with the per-package coverage floor on Linux, macOS and Windows;
real Terraform and OpenTofu plans; the embedded interface in Chromium,
Firefox and WebKit with axe-core 4.14; the website suite; gosec, staticcheck,
govulncheck and Semgrep at pinned commits; CodeQL. `govulncheck` reports no
reachable vulnerability with Go 1.27.3.
