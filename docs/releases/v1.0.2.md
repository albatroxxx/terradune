# Terradune v1.0.2

Fixed route-table associations using `for_each` so matching subnets are
connected before apply. Subnets without a known association no longer show
a misleading private label.

This is a historical release summary. For the supported Go installation,
see the [current guide](https://albatroxxx.github.io/terradune/docs/).
The [original release record](https://github.com/albatroxxx/terradune/releases/tag/v1.0.2)
retains publication details.
