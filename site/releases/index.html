RELEASE NOTES

Terradune v1.0.0

First stable release

A local review workspace for Terraform plans, distributed through Docker and Go.

Review infrastructure in context

  • Resource Map with directional paths, direct associations, workspace-isolated pins, and an expandable canvas.
  • A complete managed-resource Plan register with service, workspace, action, and search filters.
  • A dependency Graph with focused neighborhoods, routed arrows, zoom, fit, and keyboard controls.
  • A resource inspector with before/after values, unknown states, and sensitive-value masking.

Built for repeatable local use

  • Multi-platform Docker images for Linux AMD64 and ARM64, with Terraform included and a non-root default user.
  • Versioned Go installation with accurate -version output.
  • Coalesced rebuilds, bounded plan concurrency, latest-snapshot delivery, and signal-aware shutdown.
  • Pinned container bases, container smoke tests, vulnerability gates, SBOM, and build provenance.

Stable v1 defines a supported review workflow, not complete Terraform lifecycle parity. Read the compatibility boundary before adopting it.
